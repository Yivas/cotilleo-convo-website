# Contributing

Documentation corrections, site proposals, issues and pull requests are accepted. The repository has no website source, package manager, build, preview or deployment command yet. Contributions must not imply that a site or plugin capability already exists.

## Issues

The [issue chooser](https://github.com/Yivas/cotilleo-convo-website/issues/new/choose) offers problem and proposal forms. Existing [issues](https://github.com/Yivas/cotilleo-convo-website/issues) should be checked first. Reports should identify the document or commit, relevant environment, steps, expected behavior and observed behavior. A site proposal should describe its audience, task and content requirements rather than assume an approved visual design.

Sensitive concerns use [SECURITY](SECURITY.md). Credentials, private conversations, prompts, personal paths and operational configuration must not enter public content or attachments.

## Pull requests

A [pull request](https://github.com/Yivas/cotilleo-convo-website/pulls) should keep one coherent change and explain its motivation, checks performed, compatibility, risks and documentation impact. Building or deploying the future site needs a separate agreed scope; a submitted proposal does not authorize deployment or new services.

For current documentation, review the text and affected links. There are no build commands to report and no string-presence tests are expected. Unperformed or inapplicable checks should be identified. Review and acceptance have no promised date.

# Cotilleo Convo website

The repository for the planned public Cotilleo Convo website and documentation.

**Pre-development: no website implemented or deployed.** This repository contains documentation only, with no site source, build system, packages or deployment workflow.

[Contribute](CONTRIBUTING.md) · [Issues](https://github.com/Yivas/cotilleo-convo-website/issues) · [Security](SECURITY.md)

## Planned scope

The future site should explain Cotilleo Convo and document the standalone [Pi](https://github.com/Yivas/cotilleo-convo-pi) and [OpenCode](https://github.com/Yivas/cotilleo-convo-opencode) plugins as their capabilities become available. Both plugins are currently in pre-development; planned capabilities must not be presented as working features.

GitHub Pages is the intended future static hosting destination. The balance between a landing page and task-oriented documentation, navigation and visual identity has not been decided. There are no installation or local preview instructions because there is no executable site yet.

## Boundaries

The website will not act as an agent host, remote-control server or relay. Private conversations, operational configuration and credentials do not belong in its content. Desktop and mobile applications are outside this repository's current scope.

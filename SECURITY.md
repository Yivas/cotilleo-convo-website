# Security policy

## Supported lines

| Line | Status |
| --- | --- |
| Pre-development documentation on main | Reports about repository content are accepted |
| Deployed website or released site builds | None |

This repository has no deployed site, server, relay or agent-control endpoint. GitHub Pages is a future static hosting destination, not an execution or authorization boundary for agents.

## Reporting a concern

[GitHub private vulnerability reporting](https://github.com/Yivas/cotilleo-convo-website/security/advisories/new) is enabled for this repository. Accidental disclosure and other sensitive concerns should be reported there, not in public issues or pull requests. If the form is unavailable, a public issue may request a private contact without disclosing details.

A report should identify the affected file or commit, relevant environment, sanitized reproduction, expected and observed behavior, impact and any workaround. A document link is sufficient while no website version exists.

Credentials, tokens, personal paths, private conversations, prompts and operational configuration must be removed. Evidence should not reproduce private content publicly, and reporting does not authorize testing third-party infrastructure or causing damage.

Yivas will assess the scope, request clarification when needed and coordinate any correction or disclosure. No response deadline, reward, CVE assignment or embargo is promised.
